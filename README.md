# Android Mirroring: Downloads

This repo holds the downloads for **Android Mirroring**, a macOS app that mirrors and controls an Android phone over USB, Wi-Fi or the phone's personal hotspot. It's built on [scrcpy](https://github.com/Genymobile/scrcpy).

**[⬇︎ Download the latest version](https://github.com/7t64vu3ge/Android-Mirroring-Releases/releases/latest)**

## Install

1. Download `AndroidMirroring-vX.Y.Z.zip` from the latest release and unzip it.
2. Install the tools once: `brew install scrcpy && brew install --cask android-platform-tools`
3. Drag **Android Mirroring.app** into **Applications** and open it. If macOS blocks it, go to **System Settings → Privacy & Security → Open Anyway**.
4. On the phone, turn on **USB debugging**, plug it in once, and tap **Allow**.

The zip includes **Setup Guide.txt** with the full steps.

## Updates

From v1.2.0 on, the app checks this page for new versions. When one is available, it shows an **Update Now** banner that downloads and installs the update for you. You can also use **Android Mirroring › Check for Updates…**.
